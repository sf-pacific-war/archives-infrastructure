# Documentation

This directory contains the human-readable knowledge base for the archives
program.

Use these folders to keep program intent, requirements, standards, meeting
history, and decision logic in version control instead of scattering them across
chat threads and ad hoc notes.

Current top-level authoring flow:

- `docs/planning/` for scope, track definitions, and requirement drafts
- `docs/standards/` for stable descriptive, rights, and digitization rules
- `docs/architecture/` for system and application design
- `docs/decisions/` for ADRs and governance choices
- `docs/meetings/` for discussion history

## GitHub Pages Showcase

The repository root contains `index.html`, a GitHub Pages-ready showcase that
links the current stakeholder HTML pages:

- program scoping, requirements, and tracks
- research patterns to follow, learn from, or leverage
- archival infrastructure architecture proposal
