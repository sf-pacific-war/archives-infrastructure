# Archives Infrastructure Scope Boundaries

## Purpose

This note records how the archives infrastructure project relates to the earlier
intern project document so that scope boundaries remain explicit.

## Included in the archives infrastructure project

### Directly included

- collection inventory and digitization planning
- digital collections management and archival description
- external archives metadata aggregation and interoperability
- digital reading room discovery and access

### Included in adapted form

- historical website archive work where it functions as:
  - born-digital collection inventory
  - structured description of exhibition-history materials
  - discovery/access content tied to archival records

## Not included in the archives infrastructure project

- volunteer management platform
- AI voice narrator / audio guide project
- other organizational products that may sit alongside the archives
  infrastructure work but are not part of these four tracks

## Interpretation rule

If a work item is about archival inventory, description, metadata aggregation,
or reading-room access, it belongs in this project.

If a work item is primarily about onsite interpretation, volunteer operations,
or a parallel product line, it should be planned in a separate project area.
